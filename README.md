
# Student Management App

## Project Overview

The Student Management App is an Android application developed using Java and XML for Android Application Development Assignment 2.

The application demonstrates common mobile application screens, user input validation, Activity navigation, Android layouts, and support for light and dark themes.

## Technologies Used

- Java
- XML
- Android Studio
- Android SDK
- Git and GitHub

## Application Features

### 1. Splash Screen
Displays the application identity when the app launches.

### 2. Login
Provides email/username and password input fields, along with Login, Register, and Forgot Password navigation.

### 3. Registration
Allows users to enter their name, email, password, and confirm password.

### 4. Forgot Password
Accepts an email address and initiates the simulated password recovery process.

### 5. Reset Password
Allows users to enter and confirm a new password with validation.

### 6. Dashboard
Displays the main student management modules using cards or a grid with icons and text.

### 7. Profile
Displays user information and provides a Logout option.

### 8. Light and Dark Mode
Supports light and dark appearances using Android alternative resources.

## Technical Concepts Demonstrated

- LinearLayout
- GridLayout
- ConstraintLayout
- String and color resources
- Alternative night-mode resources
- Text, email, and password input controls
- Button click event handling
- Input validation
- Explicit Intents for Activity navigation

## Navigation Flow

Splash Screen → Login → Dashboard

From Login, users can navigate to Registration or Forgot Password.

Forgot Password → Reset Password

Dashboard → Main Modules or Profile

Profile → Logout → Login

## How to Run the Project

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle synchronization to complete.
4. Connect an Android device or start an emulator.
5. Select the app run configuration.
6. Click Run to launch the application.

## Authentication

Authentication and password recovery are simulated locally for this academic assignment. A backend server is not required.
